# CampusFlow
Projek Pemrograman Web Lanjut
https://campus-flow-flax.vercel.app/

## Tech
1. React.JS
2. TSX

## Library
1. swiper
2. lucid-react (Ikon)
3. react-day-picker

## Design
1. Font: Commissioner - From Google Font
2. Navbar interaktif

## Login Page

1. Input username dan password

## Dashboard Page

1. Ringkasan tampilan IPK, total SKS, dan jumlah tugas
2. Tampilan jadwal sesuai hari yang sedang berlangsung
3. Kalender jadwal
4. Daftar Tugas yang ada

## Jadwal Page

1. Tampilan seluurh jadwal hari
2. Detail jadwal yang menampilkan tugas dan materi per matkul yang dipilih

## Profile Page 

1. Foto profile
2. Ringkasan IPK, Tagihan, dan Kelas
3. informasi detail terkait biodata mahasiswa

## Navigasi

1. Logo
2. Link ke dashboard
3. Link ke jadwal
4. Link ke profile dengan icon foto profile
5. logout button
